# Production T3 evaluation design

The production model is frozen by commit `1f31956` and manifest checkpoint SHA-256. Evaluate that exact checkpoint once on the frozen 706-row Gate B.2 stress set, without rerunning the historical T2/T3 comparison. Score the 350-row human reference subset separately, joining by utterance ID and checking its gold T3 labels against the stress CSV. Write only aggregate reports to `reports/nlp_v2/production_eval`; never alter frozen assets or original Gate B.2 reports.

The evaluator records input hashes, manifest and checkpoint hashes, strict intent accuracy/Macro-F1 and per-class precision/recall/F1, ambiguity-aware acceptance, exact operation mapping accuracy, contrast-group accuracy, and language/code-switch/noise strata. It also audits train/evaluation family overlap using metadata only. The frozen stress set proved to have 187 of 706 rows overlapping training semantic families, and the 350-row human subset has 160 overlapping rows. These full-set scores are therefore descriptive frozen-stress results, not independent family-held-out estimates. These are **model-only** results. Clarification execution and domain answer quality are not yet measurable and must not be inferred from the classifier score. Save no examples or individual predictions in the committed report. The run must reject output overwrite and fail on reference mismatch. No held-out results may drive model or prompt changes.
